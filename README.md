성인 보호자들이 아이의 수유·수면·기저귀·체온 등을 기록하는 모바일 앱과 웹 대시보드입니다. 현재 버전은 **0.3.0 개인 테스트 버전**입니다.

**[Android APK 다운로드](https://github.com/wjdghks1228/mybaby_project1_report/raw/refs/heads/main/downloads/ai-ssukssuk-0.3.0-debug.apk)** · **[웹 성장일지](https://baby-ssukssuk-report.wjdghks1228607146.chatgpt.site)**

Android 8.0 이상에서 사용합니다. 이전 버전을 설치했다면 **앱을 삭제하지 말고 새 APK를 열어 업데이트**하세요. 같은 앱 ID와 서명 인증서로 빌드하며, 기존 기기 기록 저장 형식을 유지합니다.

## 가족 세 사람이 함께 시작하기

1. 첫 보호자가 기존 기록을 먼저 백업하고, 앱을 업데이트합니다.
2. 홈의 가족 연결 또는 마이 → 가족 기록함 연결을 누릅니다.
3. 현재 아이로 가족 기록함 만들기를 선택하고 보호자 표시 이름과 가족 PIN 네 자리를 설정합니다. 저장·공유 안내를 확인하고 시작하면 기존 아이 프로필과 기록이 Sites DB로 업로드됩니다.
4. 마이 → 가족 초대 링크 만들기를 눌러 다른 보호자 한 사람에게 링크를 전달합니다. PIN은 별도로 전달합니다.
5. 초대받은 사람은 앱 설치 후 링크를 열거나 첫 화면의 가족에게 초대받았어요에서 링크를 붙여넣고 참여합니다. 한 링크는 24시간 동안 한 기기에서 한 번만 사용할 수 있으므로 사람마다 새 링크를 만들어주세요.
6. 이후에는 연결된 기기에서 같은 가족 PIN으로 입장합니다. 아내·다른 보호자는 ChatGPT 계정이 필요하지 않습니다.
7. 기록은 입장 중인 앱에서 자동 업로드됩니다. 다른 보호자는 홈의 기록 최신화를 눌러 새 기록을 내려받습니다.

Android의 링크 연결이 완료되지 않으면 앱의 가족에게 초대받았어요에 링크를 직접 붙여넣으세요. 웹 브라우저와 APK는 별도 기기로 연결됩니다. 초대 링크를 브라우저에서 이미 사용했다면 APK에는 새 초대 링크가 필요합니다.

## 테스트 기록 초기화와 가족 기록함 삭제

**마이 → 가족 공동 기록 → 초기화와 삭제**에서 사용합니다. 서버 연결과 PIN 입장이 필요합니다.

- **기록 전체 초기화**: 아이 프로필·가족 PIN·연결된 기기·초대 링크는 유지합니다. 기록·기록 수정 이력을 지우고 새 기록부터 시작합니다. 이전 전송 대기 기록과 수면·모유 타이머도 다음 최신화 때 정리하며, 오래된 휴대폰이 삭제 전 기록을 다시 업로드하지 못하도록 차단합니다.
- **가족 기록함 삭제**: 공동 DB의 아이 프로필·기록·변경 이력·초대·모든 기기 권한과 세션을 삭제합니다. 삭제한 기기는 시작 화면으로 돌아갑니다. 다른 기기의 가족 캐시는 다음 서버 연결 때 정리합니다. 가족 기록함을 새로 만들면 다시 초대해야 합니다.
- 두 작업 모두 모든 가족에게 적용되며 되돌릴 수 없습니다. 아이 이름·가족 PIN·지정된 확인 문구·동의 체크를 요구합니다. 확인 중 다른 가족이 기록을 변경했다면 최신 내용을 다시 확인해야 합니다.
- 같은 아이의 가족 연결 전 개인 기록 사본은 이 기기에서 함께 정리합니다. 별도로 내보낸 백업 파일과 인터넷에 연결되지 않은 기기의 데이터를 즉시 원격 삭제할 수는 없습니다.
- 초기화 후에는 모든 보호자가 **0.3.0 이상으로 업데이트**해야 합니다. 이전 앱의 최신화는 오류로 차단하여 기록이 되살아나는 것을 막습니다. APK 업데이트 시 기존 앱을 삭제하지 않습니다.

## 자동 업로드와 수동 최신화

- 홈에서 마지막 최신화 시각과 전송 대기 건수, 오류·충돌을 확인할 수 있습니다.
- 인터넷이 끊기면 기기에 전송 대기 기록을 저장하며, 앱이 실행되고 입장된 상태에서 다시 연결되면 전송합니다. 앱을 완전히 종료한 동안의 네이티브 백그라운드 전송은 제공하지 않습니다.
- 앱을 새로 열 때 PIN 확인에는 인터넷이 필요합니다. 미전송 데이터는 PIN 입장 실패나 통신 오류에도 삭제하지 않습니다.
- 전체 데이터를 통째로 덮어쓰지 않고 기록별 작업 ID·수정 버전을 사용합니다. 서로 다른 기록은 함께 반영하고 같은 기록을 동시에 수정하면 어떤 내용을 유지할지 선택합니다. 수정창이 열린 동안 새 버전이 도착했다면 저장·삭제 전에 최신 내용을 다시 확인하도록 막습니다.
- 삭제는 삭제 이력으로 다른 기기에 전파하여 오래된 기록이 다시 살아나지 않도록 합니다.
- 동시에 두 개의 진행 중 수면을 만들지 않도록 서버와 DB에서 확인합니다. 완료된 수면의 겹친 구간은 누적 시간에서 중복 계산하지 않습니다.
- 진행 중 모유 수유 타이머는 해당 기기에 보관하며, 종료한 기록을 공동 DB에 올립니다.

## 데이터 위치와 접근

- 가족 연결 전 개인 기록: 해당 기기의 `localStorage`.
- 가족 연결 후 공동 원본: ChatGPT Sites가 프로비저닝한 Cloudflare D1.
- 연결 후 기기의 캐시·전송 대기열: 해당 기기의 별도 `localStorage` 키.
- 앱 코드·APK: GitHub. 실제 가족 기록과 DB·인증정보는 GitHub에 올리지 않습니다.
- 기존 개인 기록은 가족 캐시와 구분해 보존합니다. 가족 참여가 기존 개인 기록을 덮어쓰지 않습니다.

기기 연결에는 임의로 생성한 긴 기기 권한 키를 사용하며 네 자리 PIN만으로 새 기기 접속을 허용하지 않습니다. 서버에는 PIN 해시·기기 키와 세션 키의 해시를 보관하고, PIN 실패 횟수를 제한합니다. 네 자리 PIN은 원격 접속 권한을 대체하는 강력한 암호가 아니며, 개인 휴대폰의 화면 잠금도 유지해주세요. 기기 권한 키는 WebView/브라우저 저장소에 보관되며 이 버전에서 앱 자체 암호화 저장소는 별도로 구현하지 않았습니다.

앱의 통신 대상은 지정된 Sites의 HTTPS API로 한정합니다. Sites 입장 화면은 공개되어 있지만, 기록 API는 초대받은 기기의 인증·PIN 입장 세션과 가족별 권한을 확인합니다. 임의 사용자의 신규 가족 생성 요청도 횟수를 제한합니다.

이 앱은 성인 가족의 일상 기록용입니다. 의료기관 진료 문서·HIPAA상 PHI 업로드, 의료기관 연동이나 진단용으로 제공하지 않습니다. 실제 기록은 앱의 저장·공유 안내에 동의하고 연결했을 때만 외부에 저장됩니다.

## 백업과 연결 해제

마이 → 데이터 관리에서 JSON으로 내보냅니다. 백업에는 아이 정보·건강 기록이 포함되므로 개인적으로 보관하고 공개 저장소나 공개 링크로 공유하지 마세요. 연결 키·PIN·접속 세션은 백업에 넣지 않습니다.

가족 기록함에서는 백업으로 전체 데이터를 교체하는 복원을 막아 다른 가족의 기록을 보호합니다. 개인 모드에서만 전체 교체 복원을 지원합니다. 이 기기 연결 해제는 해당 기기의 서버 권한과 가족 캐시를 제거하며 다른 기기의 기록은 삭제하지 않습니다. 전송 대기 기록이 있으면 먼저 최신화해야 합니다.

잊은 PIN 복구, 분실 기기 원격 관리, 전체 가족 기록함 폐기는 관리 UI의 후속 항목입니다. 삭제 이력·수정 로그는 동기화를 위해 서버에 보존됩니다. 개인 테스트 단계이므로 정기적으로 백업하세요.

## 개발과 재빌드

Node.js 22.13 이상에서 외부 패키지 설치 없이 사용할 수 있습니다.

```bash
npm test
npm start
```

로컬 웹 미리보기는 `http://localhost:4173`입니다. 실제 가족 연결·통신 검증에는 위의 배포된 웹 주소를 사용합니다.

```bash
npm run build
npm run android:assets
cd android
JAVA_HOME='/home/jhkim05/ai-ssukssuk/.tools/java/jdk-17.0.21+9' \
ANDROID_HOME='/home/jhkim05/ai-ssukssuk/.tools/sdk' \
GRADLE_USER_HOME='/home/jhkim05/ai-ssukssuk/.tools/gradle-home' \
../.tools/gradle-8.9/bin/gradle --offline --no-daemon :app:assembleDebug :app:lintDebug
cd ..
node scripts/package-apk.mjs
```

로컬 도구 경로는 설치 위치에 맞춰 변경합니다. APK는 `artifacts/`에 생성됩니다. 배포 전달 파일은 `downloads/`에 보관합니다. debug 서명 테스트 APK이며 Play Store용 정식 서명은 별도입니다. 업데이트에는 같은 서명 키가 필요합니다.

Sites용 소스는 `/home/jhkim05/ai-ssukssuk-site`의 별도 체크아웃에서 공식 Sites 도우미로 저장·패키징합니다. D1 스키마는 `cloud/schema.sql`, 불변 배포 마이그레이션은 `drizzle/`입니다. 배포된 마이그레이션은 수정하지 말고 다음 마이그레이션을 추가합니다. 요청 처리 중 테이블을 생성하거나 변경하지 않습니다.

## 검증과 제한

기록 집계·전송 대기열·충돌·PIN 재확인·초기화 경합·삭제 후 권한 회수·클라이언트 캐시 정리를 포함한 로컬 테스트, Android 빌드와 정적 검사, APK 공개 서명·기존 버전 서명 일치를 검사합니다. 배포된 D1에서는 실제 아이 정보 없는 가상 가족 세 기기로 인증 없는 접근 차단·초대·업로드·최신화·수정·삭제·수정 충돌을 검증했습니다. 0.3.0에서는 추가로 PIN 재확인·확인 중 변경 차단·기록 초기화·오래된 기록 재전송 차단·프로필과 초대 보존·가족 삭제 후 세 기기 권한 회수를 검증하고 가상 가족을 정리했습니다. 27개 로컬 테스트가 통과했으며 Android lint는 오류 0건, 기존 경고 5건입니다.

현재 환경에는 조작 가능한 브라우저·Android 실기기가 없어 실제 터치·키보드·링크 자동 열림·화면 낭독 검증은 완료하지 못했습니다. 테스트 기록으로 업데이트·가족 연결·재실행·백업을 확인해주세요.
